What ebb-ai does

Most agent code calls LLM APIs synchronously the moment the call happens. ebb-ai sits in front of that call and answers a single question: does it have to run right now? If the agent says by tomorrow morning is fine, ebb-ai picks the cleanest hour inside that window — on the local electricity grid, at the LLM provider's cheapest tier, on whichever route makes most sense — and dispatches there. It returns the result with a per-task carbon receipt you can audit.

Why it matters

  • Carbon. US grid intensity varies 30–60% within a single day. Inference at 2 p.m. on a hot day is materially dirtier than the same call at 3 a.m.
  • Dollars. Anthropic and OpenAI both ship Batch APIs at a flat 50% discount for tasks that can wait up to 24 hours. Almost no agent code uses them by default.
  • Latency. Off-peak execution is faster end-to-end. Providers throttle at peak.

The gap is at the agent/MCP layer. There are mature carbon-aware tools upstream (Microsoft Carbon Aware SDK, Electricity Maps, WattTime, GridStatus) and downstream (Batch APIs). Nothing stitches them together for agents. ebb-ai does.

How it ships

@ebb-ai/core

TypeScript library with the scheduler, grid feeds, and the defer() API. The thing you import in your own agent code.

@ebb-ai/mcp

Model Context Protocol server. Drop-in for Claude Desktop, Claude Code, OpenClaw, Cursor, Codex, and anything else that speaks MCP. Three tools, zero integration.

ebb-ai (Python)

Same surface, PyPI package, drops into agent stacks built on the Anthropic, OpenAI, and Google Python SDKs. v0.2.

Spec proposals

Upstream PRs to the Model Context Protocol spec adding priority, deadline, and carbon_budget as first-class request fields. v0.3.

Install (development)

git clone https://github.com/Vitalini/ebb-ai.git
cd ebb-ai
pnpm install
pnpm build
pnpm test    # 11/11

Then wire @ebb-ai/mcp into your MCP-aware client. The repo ships ready-to-paste configs for Claude Code, OpenClaw, and Codex CLI.

Where we are

v0.1 lands the scheduler, the MCP server, the grid feeds (with a mock fallback for development without an API key), and examples for Claude Code, OpenClaw, and Codex. v0.2 adds provider adapters with Batch API support and a SQLite-backed durable queue. v0.3 ships the spec PRs and a public carbon dashboard.
