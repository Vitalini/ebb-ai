roadmap

Where ebb-ai is heading.

Public, dated, with what already shipped marked. Detailed plan in PLAN.md.

v0.1 — shipped 2026-05-12

  • TypeScript core library @ebb-ai/core — scheduler, mock + Electricity Maps grid feeds, defer() API, pickBestWindow helper.
  • MCP server @ebb-ai/mcp — three tools, stdio transport, MCP protocol verified end-to-end.
  • Mock grid feed with automatic fallback when no API key is set.
  • Carbon budget enforcement and ISO-8601 deadline validation.
  • Reference integrations for Claude Desktop, Claude Code, OpenClaw, OpenAI Codex CLI.
  • Static landing site under apps/site/.
  • Apache-2.0 license. Public-style community files: CHANGELOG, CONTRIBUTING, CODE_OF_CONDUCT, CODEOWNERS.
  • Engineering review and full must-fix application before release.

v0.2 — current

  • Provider adapters: Anthropic (sync + Batch) and OpenAI (sync + Batch). Real LLM dispatch, real receipts, automatic Batch-API routing when deadline allows.
  • SQLite-backed durable queue. Tasks survive process restart. Full audit log of every dispatch.
  • Python port — ebb-ai on PyPI. Same API surface, async, with aiosqlite persistence and optional Anthropic / OpenAI extras.
  • Dashboard MVP — apps/dashboard/. Live carbon-intensity map across six regions, 72-hour forecast charts, best-window planner, queue viewer.
  • Real MCP protocol smoke test via InMemoryTransport.
  • MCP spec proposal drafted for upstream (docs/spec/01-priority-and-deadline-fields.md).

v0.3 — next

  • Upstream MCP spec PRs filed and in maintainer review. Targeting priority, deadline, carbon_budget, and an audit block on CallToolResult.
  • Public hosted dashboard (deployable to Vercel) at a stable URL, showing aggregated opt-in stats and live grid intensity across all major LLM-provider regions.
  • WattTime marginal-emissions feed. Default grid signal moves from average to marginal where available — the honest climate signal for time-shifting.
  • Gemini Batch adapter and a local Ollama adapter for laptop / edge dispatch.
  • Cross-provider routing — for a given prompt, pick the cheapest carbon-weighted route across {Anthropic, OpenAI, Gemini, local}.
  • ESG / SEC-disclosure-friendly carbon receipt export. CSV + JSON + a printable monthly report.
  • Multi-region failover with regional privacy locking (us-only, eu-only hints).

v1.0 — when the surface is stable

  • Frozen public APIs across TS and Python.
  • Adapters for at least one ISO/RTO demand-response program (PJM / ERCOT / CAISO).
  • Documented partner integrations with at least three first-party MCP hosts.
  • One peer-reviewed publication on agent-workflow carbon-aware scheduling patterns.
